# Trendwatch Skill — Sports Picks Affiliate

## Purpose
Mine TikTok/Instagram for what's already working in the sports picks / sports betting niche,
then generate 10 adapted hook ideas we can turn into carousels this week.

## Run this skill by saying:
"Run trendwatch for sports picks"

---

## Step 1: Bootstrap
Check if these files exist and load them:
- `trendwatch/brief.md` — product brief (always load this first)
- `trendwatch/experiments.md` — past learnings (load if exists)
- `trendwatch/current-plan.md` — current posting plan (load if exists)
- Most recent `trendwatch/trends/YYYY-MM-DD.md`

If experiments.md exists, summarize what has already been learned before proceeding.

---

## Step 2: Auto-Research (before asking anything)

Search TikTok Creative Center and web for:
1. Top performing sports picks / betting tip carousels posted in last 14 days
2. Accounts 10k–250k followers posting picks content (not just highlights)
3. What hook formats are currently getting saves in this niche

Search queries to use:
- "sports picks tiktok viral 2026"
- "lock of the day tiktok carousel"
- "best bets today tiktok"
- "parlay picks tiktok saves"
- site:tiktok.com sports picks carousel

---

## Step 3: Collect Competitor Data

For each competitor video found, extract:
- Account handle + follower count (must be under 500k)
- View count
- Estimated save rate (if visible)
- Hook text (first slide / first 3 seconds)
- Format type (carousel, video, talking head, text-only)
- Posting time
- CTA placement

Save each account to `trendwatch/competitors/{handle}.md`

---

## Step 4: Decompose on 7 Axes

For each top-performing post:
1. **Hook mechanic** — curiosity gap / social proof / FOMO / result reveal / controversy
2. **Format** — carousel text-only / carousel with image / video / talking head
3. **Emotional trigger** — greed / FOMO / trust / entertainment / validation
4. **Specificity** — vague vs specific ("4-1 last week, here's tonight's lock")
5. **CTA type** — soft follow / hard link / promo code / DM me
6. **Save trigger** — is there a reason to save this?
7. **Niche angle** — NFL / NBA / UFC / soccer / parlay / props

---

## Step 5: Generate 10 Hook Ideas

For each idea provide:
- **Slide 1 text** (the hook — under 8 words)
- **Slides 2–5 outline**
- **Final slide CTA**
- **Which affiliate offer to promote** (Ghostsportzpickz / Lev's Locks / GOAT Sports Bets)
- **Reference URL** — actual video that inspired this
- **Why this should get saves**

Prioritize hooks that:
- Lead with a specific result ("went 5-1 last week")
- Create urgency ("tonight's lock")
- Have a save reason ("screenshot the picks")

---

## Step 6: Log Everything

Save to `trendwatch/trends/YYYY-MM-DD.md`
Update `trendwatch/experiments.md` with new insights
Update `trendwatch/current-plan.md` with top 3 hooks to make THIS WEEK

---

## Engagement Rules
- Only study accounts with 10k–250k followers
- Save rate beats likes — if a post has more saves than likes it's a winner
- Specific numbers always beat vague claims
- "Tonight's lock" always outperforms "daily picks"
- Only use audio from videos posted within 14–30 days

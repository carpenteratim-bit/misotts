# Sports Picks Affiliate Engine

## What This Is
An affiliate content operation promoting sports picks communities on Whop.
We post carousels on TikTok, Instagram Reels, and YouTube Shorts.
Traffic flows to affiliate links. Conversions = someone joins a paid picks community.

## Affiliate Offers
- Ghostsportzpickz: 20.44% conversion rate, $8.12 EPC
- Lev's Locks: 16.95% conversion rate, $15.87 EPC (primary — highest EPC)
- GOAT Sports Bets: 8.46% conversion rate, $3.74 EPC

## Folder Structure
```
trendwatch/          # Research and trend analysis
  SKILL.md           # How to run trendwatch
  brief.md           # Product brief and audience
  experiments.md     # What's working / not working (compounding asset)
  current-plan.md    # What to post this week
  trends/            # Daily trend snapshots
  ideas/             # Daily hook ideas
  competitors/       # Per-account research files

content/
  covers/            # Reusable carousel cover images
  carousels/         # Finished carousel slides ready to post
  scheduled/         # Posts queued for Postiz
```

## Key Commands

### Run trend research
"Run trendwatch for sports picks"
→ Reads brief.md, finds what's working on TikTok right now, generates 10 hook ideas

### Generate a carousel
"Make a carousel for [hook idea from current-plan.md]"
→ Outputs 5-slide carousel text, specifies which affiliate offer to promote

### Check what to post this week
"What's in current-plan.md?"

## Rules
- Never post generic content — always specific results or specific picks
- Primary metric: save rate (target 2-3%+)
- Only promote Whop affiliate offers — Ghostsportzpickz, Lev's Locks, GOAT Sports Bets
- Post times: 8:30am / 11:30am / 9:00pm local
- Always include a save reason in every carousel
